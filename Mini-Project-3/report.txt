
======================================================================
THEORETICAL CONCEPTS DEMONSTRATION
======================================================================

1. KNOWLEDGE-BASED AGENT ARCHITECTURE:
   KB = Facts + Rules
   Agent = Perceive → Update KB → Infer → Act

2. LOGIC REPRESENTATION (Horn Clauses):
   Rules are Horn Clauses: (A ∧ B ∧ ...) → C
   Example: presence(?room) ∧ dark(?room) → turn_on_light(?room)
   - Conditions: Conjunctions of predicates (can have variables)
   - Conclusion: Single predicate to infer

3. FORWARD CHAINING (Data-Driven Inference):
   • Start from known facts (environmental observations)
   • Repeatedly match and apply rules
   • Add newly inferred facts to KB
   • Stop at FIXPOINT (no new facts can be inferred)
   - This is DATA-DRIVEN reasoning (facts trigger rules)

4. VARIABLE UNIFICATION:
   Pattern: ('presence', '?room')
   Fact: ('presence', 'kitchen')
   Substitution: {?room: 'kitchen'}
   - Enables generic rules applicable to all rooms

5. EXPLAINABILITY:
   Every inference includes:
   • Which rule fired
   • Which conditions matched
   • What was concluded
   • Variable substitutions used
